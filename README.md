## ✨ Features

- 🩺 **Health Risk Assessment** — 7-factor scoring for diabetes, BP, and heart disease risk
- 📊 **Blood Report Parser** — paste lab report text and get instant color-coded results
- 🥗 **7-Day Indian Diet Plans** — condition-specific meal plans with Indian foods
- 💊 **Medicine Reminders** — browser notifications for daily medicines
- 👨‍👩‍👧‍👦 **Family Health Tracker** — track risk scores for every family member
- 💡 **Health Tips** — 35+ science-backed tips in Hindi & English, shareable on WhatsApp
- 🌐 **Bilingual** — full Hindi + English support
- 🌙 **Dark / Light Mode** — smooth theme toggle
